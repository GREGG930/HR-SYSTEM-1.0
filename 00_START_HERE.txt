================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: npm: command not found
SOLUTION: Node.js not installed. Download from https://nodejs.org/

PROBLEM: Cannot find module
SOLUTION: Run: npm install

PROBLEM: Port 3000 already in use
SOLUTION: Run: PORT=3001 npm start

PROBLEM: Cannot GET /
SOLUTION: Ensure server is running and public/index.html exists

PROBLEM: No sample data displays
SOLUTION: Delete data/hr_database.db and restart server

PROBLEM: Cannot connect to server
SOLUTION: Make sure you are using http://localhost:3000 (not https)

MORE HELP: See SETUP_INSTRUCTIONS.md Troubleshooting section
