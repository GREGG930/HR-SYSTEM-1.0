HOW TO GET STARTED

Step 1: Installation (2-3 minutes)
   - Download Node.js from nodejs.org
   - Install Node.js on your computer
   - Navigate to project folder
   - Run: npm install

Step 2: Start Server (1 minute)
   - In project folder terminal
   - Run: npm start
   - Wait for "Server running on http://localhost:3000"

Step 3: Access System (30 seconds)
   - Open web browser
   - Navigate to: http://localhost:3000
   - See dashboard with sample data

Step 4: Create Backup (2 minutes)
   - Run: CREATE_BACKUP.bat
   - ZIP file created on Desktop
   - Store in safe location

Total Setup Time: Approximately 5 minutes
