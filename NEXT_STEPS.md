## Troubleshooting Quick Reference

### Issue: "npm: command not found"
Solution: Install Node.js from nodejs.org

### Issue: "Port 3000 already in use"
Solution: PORT=3001 npm start

### Issue: "Cannot GET /"
Solution: Wait for server to fully start, check http://localhost:3000

### Issue: No sample data shows
Solution: Delete data/hr_database.db and restart

### Issue: Database errors
Solution: Check data/ folder exists, restart server

For more help, see SETUP_INSTRUCTIONS_CLEAN.md troubleshooting section

3. Store in safe location
